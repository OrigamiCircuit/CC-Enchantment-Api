## Dependencies

This project builds upon the following projects and technologies:

- [Minecraft](https://www.minecraft.net/) - Game platform.
- [Minecraft Forge](https://files.minecraftforge.net/) - Mod loader and modding framework.
- [CC:Tweaked](https://tweaked.cc/) - Computer and programmable peripheral mod.
- [Enchantment Descriptions](https://modrinth.com/mod/enchantment-descriptions) - Optional dependency, allows for the usage of `getEnchantmentDescriptionKey()` and `getEnchantmentDescription()`.
- [Java](https://www.oracle.com/java/) - Programming language.
- [Gradle](https://gradle.org/) - Build automation system.
