# CC Enchantment API

A Minecraft Forge mod for CC:Tweaked that provides an API for accessing, retrieving, and managing enchantments through computer and peripheral interactions.

## Overview

CC Enchantment API is designed to make Minecraft enchantments accessible to CC:Tweaked computers and compatible peripherals.

The goal is to provide reusable functionality for working with enchantments, including:

- Retrieving enchantment information.
- Obtaining enchantment names and levels.
- Checking whether enchantments can be combined.
- Working with enchanted item stacks.
- Providing consistent enchantment-related functions for other mods and scripts.

## Requirements

- Minecraft 1.20.1
- Minecraft Forge 47.x
- CC:Tweaked

## Installation

1. Install Minecraft Forge 1.20.1.
2. Install CC:Tweaked.
3. Place the CC Enchantment API JAR file into your Minecraft `mods` directory.
4. Launch Minecraft.
